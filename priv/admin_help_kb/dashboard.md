# Admin dashboard and navigation

The dashboard at `/admin` is the landing page for both roles. It greets you with "Welcome back, {FirstName}" and includes a global admin search.

## Shared widgets (both roles)

- **Upcoming events** timeline — each event shows per-tier sold/capacity and revenue, with **View**, **Edit**, and **Check-in** buttons. Empty state: "No upcoming events".
- **Recent discussions** — the latest 5 member comments on published posts. Empty state: "No new comments to moderate". Worth a glance; replying to member comments is good practice.

## Volunteer stats row (3 cards)

1. **Upcoming Events** — count plus the next event's title/time → "Manage events →".
2. **News & Posts** — published count and draft count → "Manage posts →" (drafts shown so unfinished work isn't forgotten).
3. **Newsletters** — sent editions count and draft/scheduled count → "Manage newsletters →".

## Admin-only widgets

- **Applications** — pending membership applications count, This Month / YTD with % change → "Review applications →"; plus a queue of up to 3 pending applicants with status badges (New / Pending / Overdue).
- **Active memberships** — totals, new members YTD vs prior year, Single/Family/Lifetime breakdown, renewals due in 30 days.
- **Pending Refunds** — count by property (Tahoe / Clear Lake) or an "All clear" badge.
- **Property matrix** — Tahoe and Clear Lake cards: who's staying now, checking in/out today, next 14 days bookings/guests.
- **Financials** — total revenue for the month, YTD, month-over-month and year-over-year change with sparkline; revenue mix across Bookings / Events / Memberships; cabin revenue split.
- **Recent newsletters** — last 5 sent editions with sent counts, open % and click % badges, active subscriber count, and new subscribers this month.

## Sidebar

- Dark sidebar on the left; collapsible via the chevron at top (preference remembered).
- Volunteer items: Overview, Posts, Events, Newsletters, Media, Help.
- Admin extras: Bookings, Users, Memberships, Money, Settings (some depend on board positions — see roles document).

## Getting around

- The round **Admin** floating button on the public site (bottom corner) jumps into `/admin` for staff.
- Every major admin screen has a small **?** help link near the title that opens the matching interactive guide.
- The Help section (`/admin/help`) contains step-by-step illustrated guides, an AI guide finder, and Print/Save-PDF buttons on every guide.
